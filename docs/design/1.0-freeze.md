# Design: 1.0 contract freeze checklist

**Status:** freeze checklist (do not cut `1.0.0` until blockers are green)  
**Related issue:** [#148](https://github.com/Mellow-Artificial-Intelligence/openextract/issues/148)

## Public symbols (`openextract.__all__`)

| Symbol | 1.0 status | Notes |
| ------ | ---------- | ----- |
| `extract` | Stable | Primary sync API |
| `extract_async` | Stable | Async sibling |
| `extract_with_usage` | Stable | `(T, Usage)` tuple |
| `extract_with_usage_async` | Stable | Async sibling |
| `extract_many` | Provisional | Batch; event-loop guard → use `extract_many_async` |
| `extract_many_async` | Provisional | Async batch |
| `Usage` | Stable | `input_tokens`, `output_tokens`, `total_tokens` |
| `ExtractionError` | Stable | Base |
| `UrlFetchError` | Stable | URL / SSRF failures |
| `SchemaValidationError` | Stable | Schema mismatch |
| `ModelError` | Stable | Provider/model failures |
| `ProviderNotInstalledError` | Stable | Missing extra |
| `InputTooLargeError` | Stable (once shipped) | Subclass of `ExtractionError`; CLI exit `5` |

## CLI contract

| Item | Freeze decision |
| ---- | --------------- |
| Exit codes `0`–`7` | **Frozen** for 1.0 |
| Oversized input | Map to existing `5` (`ExtractionError` path); no new exit code |
| stdout / stderr | Successful payloads on stdout; errors/warnings on stderr (`docs/cli.md`) |
| `--output json` / `repr` | Frozen; `jsonl` is additive batch mode |
| Command / core flags | Provisional overall, but exit-code table above is frozen |

## Python support

- `requires-python = ">=3.12"` (from `pyproject.toml`)
- Dropping a Python minor is a breaking change and must be announced in
  `CHANGELOG.md`

## Blockers before `1.0.0`

1. Input size limits implemented and documented (#143).
2. Live smoke covers ≥3 representative providers (#144).
3. Provider matrix promotions match evidence (#145).
4. Pending Unreleased / `0.10.0` packaging shipped or explicitly deferred (#147 /
   draft PR #139).
5. README API reference decision recorded (#146 — README-only).
6. Release checklist dry-run in `CONTRIBUTING.md` executed against `main`.
7. Phase 2 release gates (ruff, ty, pytest + 100% coverage) green.

## Explicitly not blockers for freeze text

- Batch usage aggregation (#152) — P2; coordinate with ExtractResult design (#149).
- Rate limiting (#153) and checkpoint/resume (#154) — design/P2.
- Generated API docs — rejected for 1.0 (`docs/design/api-reference.md`).

## Process after freeze

No silent public contract changes. Follow the README compatibility and
deprecation policy. Pre-1.0 minors may still break with changelog callouts;
after `1.0.0`, breaking changes require a major version.
